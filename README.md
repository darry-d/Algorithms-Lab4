# Прикладні задачі на графах (Лабораторна робота №4)

Репозиторій містить розв'язання прикладних задач з використанням графів та алгоритмів обходу (DFS, BFS) мовою Java.

## Реалізовані алгоритми та задачі:

1. **Виявлення циклів у неорієнтованому графі** (модифікований DFS з відстеженням вершини-"батька").
2. **Прикладна задача "Карта міста"** (BFS):
   - Пошук найкоротшого шляху між районами.
   - Визначення мінімальної кількості доріг (рівнів BFS) до кожної вершини.
3. **Цільовий пошук** (DFS): пошук заданої цільової вершини з фіксацією шляху.
4. **Перевірка графу на двочастковість** (BFS-розфарбовування у 2 кольори).

## Структура графу "Карта міста" (Завдання 2):

Для тестування пошуку найкоротшого шляху було використано граф з 8 районів (вершини 0-7).

### Список суміжності:
```text
0: [1, 3]
1: [0, 2, 4]
2: [1, 5]
3: [0, 4]
4: [1, 3, 6]
5: [2, 7]
6: [4, 7]
7: [5, 6]
```
Деталі реалізації:
Графи представлені у пам'яті за допомогою списку суміжності (двовимірні масиви).

Алгоритми DFS реалізовані рекурсивно.

Алгоритми BFS реалізовані ітеративно з використанням структури даних Queue (Черга).

Для перевірки на двочастковість використано масив станів замість стандартного масиву відвіданих вершин (0 - не розфарбовано, 1 - перший колір, -1 - другий колір).
